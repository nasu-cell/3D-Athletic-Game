# 3D Athletic

> ⚠️ 開発中（v0.1.0）です。仕様や内容は今後変更される可能性があります。

## ゲーム概要

Unity 製の 3D アスレチックゲームです。
さまざまなギミックが配置されたステージを進み、ゴールを目指します。
落下やトラップに触れるとストックが 1 つ減り、直前に通過したチェックポイントから再開します。ストックが 0 になるとゲームオーバーです。

タイトル画面 → ゲーム画面 → クリア画面 の流れで遊べます。

## ゲームの特徴

- **多彩なステージギミック**: 移動床、落下ブロック、点滅ブロック、ジャンプ台、振り子、転がる丸太など、タイミングと操作が試される仕掛けを多数配置しています。
- **ストック制とチェックポイント**: ミスしてもストックが残っていれば、最後に通過したチェックポイントから再挑戦できます。
- **カメラ基準の 3D 操作**: Cinemachine による三人称カメラをマウスで操作し、カメラの向きを基準に移動します。
- **サウンドによる予告**: 点滅ブロックは切り替わる前に音で知らせてくれます。

## 操作方法

| 操作 | キー |
| --- | --- |
| 移動 | `W` `A` `S` `D` |
| ダッシュ | `Shift`（押している間） |
| ジャンプ | `Space` |
| 視点移動 | マウス |
| メニュー操作 | マウスクリック |

移動方向はカメラの向きが基準です。

## ゲームシステム・主な機能

### 画面遷移

| シーン | 内容 |
| --- | --- |
| TitleScene | タイトル画面。「Game Start」でゲームを開始します。 |
| GameScene | メインのステージ。ゴールに触れると ClearScene へ移動します。 |
| ClearScene | クリア画面。「Title」でタイトル画面へ戻ります。 |

### ストック・リスポーン

- ゲーム開始時のストック数はインスペクターの `maxStock` で設定します（現在は 15）。
- 落下エリアなどの危険な場所に触れるとストックが 1 つ減り、残り数が画面に表示されます。
- ストックが残っていれば、記録したチェックポイントから再開します。

### チェックポイント

- ステージ上にチェックポイント（SpawnPoint）が配置されています。
- 通過するとリスタート地点として記録され、目印のシリンダーが消えます。

### ゲームオーバー

- ストックが 0 になるとゲームオーバー画面が表示されます。
- 「ReStart」: ストックを最大数に戻し、最初の地点からやり直します。
- 「Title」: タイトル画面へ戻ります。

### ゴール

- ゴール（GoalPoint）に触れるとクリア画面へ移動します。

### ステージギミック

| ギミック | 説明 |
| --- | --- |
| 移動床 (FloorMove) | 指定した方向に往復する床。乗るとプレイヤーも一緒に動きます。 |
| 落下ブロック (FallBlock) | 一定時間乗っていると落下し、しばらくすると元の位置に復活します。 |
| 点滅ブロック (BlinkBlock) | 一定間隔で出現と消滅を繰り返します。切り替わる前に音で知らせます。赤と青の 2 種類があります。 |
| ジャンプ台 (JumpFloor) | 踏むと大きく跳ね上がります。 |
| 振り子 (Pendulum) | 一定のリズムで左右に振れる障害物です。 |
| 丸太 (Log / LogSpawner) | スポナーから一定間隔で丸太が転がってきます。 |
| ストックダウン (StockDown) | 触れるとストックが減ります。 |
| チェックポイント (SpawnPoint) | 通過するとリスタート地点が更新されます。 |
| ゴール (GoalPoint) | 触れるとクリア画面へ移動します。 |

## 使用技術・開発環境

| 項目 | 内容 |
| --- | --- |
| ゲームエンジン | Unity 6000.4.10f1 (Unity 6) |
| 言語 | C# |
| レンダリング | Universal Render Pipeline (URP) 17.4.0 |
| 入力 | Input System 1.19.0 |
| カメラ | Cinemachine 3.1.7 |
| UI | uGUI / TextMeshPro |
| バージョン管理 | Git / GitHub |

### 起動方法

1. このリポジトリをクローンします。
   ```bash
   git clone https://github.com/nasu-cell/3D-Athletic-Game.git
   ```
2. Unity Hub で Unity **6000.4.10f1** をインストールします。
3. Unity Hub の「追加」からプロジェクトフォルダーを開きます。
4. `Assets/Scenes/TitleScene.unity` を開き、再生ボタンを押します。

## プロジェクト構成

```
Assets/
├── Scenes/
│   ├── TitleScene      タイトル画面
│   ├── GameScene       メインのステージ
│   └── ClearScene      クリア画面
├── Prefabs/        Player・各ステージギミックのプレハブ、UI 画像
├── Scripts/
│   ├── Manager/
│   │   ├── GameManager     ストック・リスポーン・ゲーム開始の管理
│   │   ├── UIManager       ストック表示・ゲームオーバー表示
│   │   └── SceneMover      シーン遷移
│   ├── Player/
│   │   └── PlayerController    移動・ダッシュ・ジャンプ
│   └── StageGimmick/   各ステージギミック・チェックポイント・ゴールのスクリプト
├── Animator/       プレイヤーのアニメーターコントローラー
├── Materials/      ステージ用マテリアル
└── Settings/       URP の設定
```
